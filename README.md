# Kaleidoscope: Dimensions Wine (森罗物语：次元酒窖)

## 简介

**Kaleidoscope: Dimensions Wine** 是 Minecraft 1.21.1 NeoForge 平台的模组，作为 **森罗物语：酒馆** 的扩展内容模组，添加了来自多个维度的特色酒类、作物和相关物品。

本模组专注于跨维度的酿酒体验，将下界、末地等维度的特色融入独特的酒精饮品系统中。

## 前置要求

- **Minecraft**: 1.21.1
- **NeoForge**: 21.1.221+
- **必需前置**: [Kaleidoscope: Tavern (森罗物语：酒馆)](https://www.curseforge.com/minecraft/mc-mods/kaleidoscope-tavern)

## 特性

### 🍷 多维度酒类系统

#### 下界维度
- **绯红绝响** (Crimson Crescendo) - 绯红葡萄酿造的美酒
- **诡影尊爵** (Ethereal Noble) - 诡异葡萄的精华之作
- **疣域轩尼诗** (Wart Hennessy)
- **烈焰马爹利** (Blaze Martell)
- **岩浆皇家礼炮** (Magma Royal Salute)
- **黑骨拉菲** (Black Bone Lafite)

#### 末地维度
- **紫颂干邑** (Chorus Cognac) - 紫颂果风味
- **龙息白兰地** (Dragon's Breath Brandy) - 蕴含龙息之力
- **深渊波特** (Abyssal Porter)
- **静默雪莉** (Silent Sherry)
- **遗忘玛格丽特** (Forgotten Margarita)
- **幻梦泡影** (Phantom Dream Bubble)
- **终末星光** (End Starlight)
- **神血波尔多** (Divine Embryo Port)
- **龙血酒** (Draconic Blood Wine) - 以龙血酿制的传说之酒

### 🌱 特色作物

#### 下界作物
- **绯红葡萄藤** & **绯红葡萄** - 生长在下界环境的特殊葡萄
- **诡异葡萄藤** & **诡异葡萄** - 诡异森林的独特产物
- **绯红/诡异葡萄藤架** - 可种植的藤蔓支撑结构

#### 末地作物
- **迷梦果藤** - 末地特有的结果藤蔓植物

### 🧪 流体系统
- **绯红/诡异葡萄汁** - 葡萄榨汁产物
- **迷梦果汁** - 迷梦果榨取
- **龙血** - 珍贵的末地流体资源

### ✨ 状态效果
模组添加了多种独特的状态效果：
- **嗜血** (Bloodthirsty) - 攻击时恢复生命值
- **火焰攻击** (Fire Attack)
- **悖论** (Paradox)
- **报应** (Payback)
- **愤怒** (Rage)
- **凋零斩击** (Withered Slash)
